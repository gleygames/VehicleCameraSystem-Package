# Vehicle Camera System

Configurable follow cameras for cars, trucks and trailers.

## Getting started

Select the vehicle in the Hierarchy, then run **Tools › Gley › Vehicle Camera System › Set Up Vehicle Camera**.

## Requirements

Unity 2022.3 or later.
